# Web Front Recupera Item

**Recupera Item** é um sistema de **achados e perdidos** que conecta pessoas a objetos perdidos, facilitando a localização e devolução de pertences através de uma interface simples e intuitiva.

## 🚀 Tecnologias Utilizadas

- **React**
- **Vercel**

## 🖥 Funcionalidades

- Listagem de itens perdidos e encontrados.
- Pesquisa por itens encontrados ou não encontrados.
- Interface responsiva.
- Conexão com backend para gerenciar dados de usuários e itens.

## 📦 Instalação

Para rodar o projeto localmente:

1. Clone o repositório:

   ```bash
   git clone https://github.com/carlos-augusto-carneiro/Web-Front-Recupera-item.git

   ```

2. Entre na pasta do projeto:

   ```bash
   cd Web-Front-Recupera-item

   ```

3. Instale as dependências:

   ```bash
   npm install

   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm start

   ```

5. Acesse http://localhost:3000
